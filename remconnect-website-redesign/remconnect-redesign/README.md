# RemConnect website redesign prototype

A self-contained, responsive static landing-page prototype based on the supplied RemConnect screenshot and the publicly visible remconnect.io homepage.

## Run locally

Open `index.html` in a browser, or serve this folder with a local static server, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Includes

- Responsive navigation with accessible mobile menu
- Hero and primary conversion actions linked to the public application and sign-in pages
- Six role cards with working experience-level filters
- Three-step journey and cohort information panel
- Career-profile benefit section, testimonials, readiness checklist, and FAQ accordion
- Responsive CSS, focus states, reduced-motion handling, semantic landmarks, metadata, and locally stored optimized WebP images

## Important scope note

This is a standalone prototype. It does not replace files in the original RemConnect repository, modify the live website, connect to private account data, or submit application data. Existing remote application and sign-in links point to the public RemConnect service. Confirm all live statistics, testimonials, cohort details, legal links, and permissions with the business before production release.
