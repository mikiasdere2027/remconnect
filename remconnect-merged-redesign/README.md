# RemConnect merged redesign

A standalone landing-page concept that combines the root page's image-led presentation with the more complete RemConnect information architecture and responsive patterns from remconnect-website-redesign/remconnect-redesign.

## Open locally

Open index.html in a browser, or start a static server from this directory with python -m http.server 8000, then visit http://localhost:8000.

## Included

- Responsive navigation, accessible focus states, and reduced-motion support
- Six career paths with working experience-level filters
- Three-step application journey and cohort overview
- Agent profile concept, story summaries, readiness checklist, and FAQ accordion
- Mobile apply bar and local image assets
- Live application and agent sign-in routes

This folder is a separate static prototype. The original root page and remconnect-website-redesign files are unchanged. Figures and program details reflect the public RemConnect website when this concept was prepared; confirm current cohort, timing, statistics, testimonials, and legal links before production use.
